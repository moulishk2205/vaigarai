# Vaigarai: wedding photography landing page (demo)

A concept landing page for a wedding photography and film studio in Coimbatore, Tamil Nadu.

The page is one wedding day. As you scroll, a clock runs from 04:30 (the lamp is lit) to 23:10 (the last guest leaves), and the light of the page follows it: night, dawn, turmeric morning, daylight, golden hour, night again.

## What is on the page

- **04:30 Vilakku.** The studio name in Tamil, cut through by a lamp photograph that opens to full screen on scroll.
- **05:04 Kolam.** A sikku kolam that draws itself as one unbroken line, generated in code.
- **05:20 Muhurtham.** A pinned sideways sequence of the five morning rituals, with times and Tamil names.
- **09:40 Kaalai.** Three complete weddings, laid out as photo stories.
- **12:30 Sappadu.** Packages, named the way Coimbatore orders lunch.
- **17:20 Maalai veyil.** A golden-hour portrait wall.
- **18:10 Anthi.** The films section, a letterbox frame that expands to full screen.
- **19:30 Varaverpu.** Family portraits and a testimonial that lights up word by word.
- **21:00 Pathirikai.** An enquiry form styled as a wedding invitation.

## Built with

Plain HTML, CSS and JavaScript. No build step.

- [GSAP](https://gsap.com) and ScrollTrigger for the scroll animation
- [Lenis](https://github.com/darkroomengineering/lenis) for smooth scrolling
- Fonts: Tiro Tamil, Anek Latin and Anek Tamil from Google Fonts

Respects the "reduce motion" setting on phones and computers: the page shows everything without animation.

## Run it locally

```bash
python3 -m http.server 4321
```

Then open http://localhost:4321.
